# AERP 方法说明（第一版）

本文说明观测版本、预测区间、异常分类、权重更新与评分定义。系统是研究原型，不能作为临床或公共卫生决策指令。

## 1. 观测版本与截止时间

每条监测记录包含发生周期（`period_start`/`period_end`）与发布时间（`issued_at`）。同一地区、指标、周期可有多个发布时间版本；导入时保留全部原始输入，不覆盖旧版本。

- **真实历史版本回放（vintage）**：只使用 `issued_at ≤ cutoff` 且周期已结束的最新版本。
- **最终数据时间切分（final_time_split）**：使用各周期最后版本，但只保留周期结束不晚于 cutoff 的目标。修订发布时间可以晚于 cutoff，因此**不能称为真实实时回测**。
- 缺失值保持为空，不等于 0。
- 不同单位、不同时间粒度不自动混合；无人口分母时不计算人均指标。

评价目标采用固定成熟滞后（默认 28 天）上最早可见的成熟版本。该值**不等于最终真实值**。结果未成熟时标记为“待评价”。

## 2. 修订估计

对有多版本历史的序列：

1. 按报告滞后整理修订轨迹；
2. 统计成熟版本相对初报的修订幅度（允许为负）；
3. 估计近期初报在固定成熟滞后后的区间；
4. 与未来 1—4 周预测分开展示。

若历史版本不足，显示“无法估计修订过程”，并继续用原始可见数据运行。修订点估计仍作为对照。研究模式下可用已成熟修订对抽样近期未成熟周（初报为 0 时用加法）；这只传播修订抽样不确定性，不声称覆盖参数与未来随机性的全体。

## 3. 预测模型与区间

统一接口：`fit` / `predict` / `diagnostics` / `serialize_metadata`。

| 模型 | 作用 |
|------|------|
| 持续值基线 | 强制对照 |
| 阻尼趋势 | 限制短期增长率 |
| 计数回归（重训/固定） | 泊松或负二项预测分布 |
| 等权组合 | 强制对照 |
| 动态加权组合 | 仅用已成熟历史表现 |
| 异常识别与适应 | 可配置规则，不默认获胜 |
| 历史形态类比 | 对齐定性归一化曲线或对照地区，再按当前水平缩放 |
| 本地/固定/可退出迁移 | 训练期内尺度变换与来源窗口检索；退出只用已成熟评分 |
| 统一计数模型 | 所有地区共享系数，无地区截距 |
| 地区分层 | 共享季节/趋势，地区截距经验贝叶斯收缩 |
| 分层动态更新 | 分层基础上按周更新截距与一条阻尼短期斜率 |

区间来源：

- 基线与阻尼趋势：滚动历史误差分位数；
- 计数回归：泊松/负二项预测分布分位数；
- 组合：对各成功组件**对应分位数**加权平均，不是完整混合分布。

禁止用任意固定比例围绕点预测生成区间。预测计数截断为非负，并强制分位数有序。小样本返回降级/失败，不伪造训练成功。组件失败不会拖垮整个组合。

## 4. 异常分类与适应

检测方法包括稳健标准化、CUSUM、跨指标滞后比较、已成熟预测误差恶化。阈值只在扫描窗口之前的训练数据上选择。

分类限定为：

- 疑似报告过程变化
- 疑似疫情动态变化
- 数据质量问题
- 证据不足

每条异常包含触发规则、指标与时间、来源或导入批次、支持证据、冲突证据、适用限制、人工核实状态。病例与住院未同步时，不直接认定为报告变化。

适应规则：

- 报告变化：优先调整修订模块；
- 疫情动态变化：比较短/长训练窗口；可选扩大区间，但**不宣称**扩大后必然达到名义覆盖率；
- 证据不足：保留多候选；
- 误差恶化：降低对应模型权重；
- 候选未通过验证：保留原窗口或基线。
- 历史形态匹配足够强：把类比方向并入适应臂权重与区间倍率；报告跳升形态优先走修订，而不是加大传播外推。
- 国家/人群/环境标签只改变匹配权重和区间倍率，不是因果证明。

形态类比使用峰值归一化的定性曲线，或截止时间之前的对照地区序列，再按当前可见水平缩放。它**不是**真实历史住院数训练，也不估计 R0。相似度不足时降级，等权与持续值基线始终保留。

## 4.1 地区分层与人群协变量

研究问题：地区差异建模与动态更新，能否比统一模型、独立地区模型和简单组合更可靠？对照臂为持续值、统一 GLM、各地区独立 GLM、分层部分共享、分层动态更新、等权/动态组合。

实现选择：继续使用纯 NumPy 泊松 IRLS 与负二项预测分布，不用另一套 MCMC 框架。地区截距是对共享季节/趋势残差的经验贝叶斯式收缩近似，**不是**完整贝叶斯分层模型。动态更新只动截距和一条短期斜率，**不同时**自由更新传播率、报告率和易感比例。所有实验臂对同一 `ForecastTask` 预测同一组目标周。

年龄结构、家庭规模、拥挤指数仅在有值时进入。没有分年龄住院时，年龄只作地区协变量，不识别年龄组传播。未提供族裔数据时跳过该分析，不生成族裔标签。疫苗覆盖率保存为时变辅助变量，但不等于免疫人口比例。没有可靠的地区间流动矩阵时，不把国家标签当作传播网络。

留出地区不进入共享参数估计，只用协变量和全局截距冷启动。辅助变量的未来值未知时，分层预测不读取实际未来协变量。

## 5. 权重更新

动态权重只使用 `matured_at ≤ cutoff` 且已有 WIS 的历史预测，按平均 WIS 倒数分配；无可评价结果时退回等权。等权组合始终作为对照。未成熟结果不更新权重。动态组合不预设优于等权。

## 6. 评分

- **MAE**：平均绝对误差。
- **WIS**：Bracher 等（2021）加权区间评分，使用中位数与 50%/80%/95% 区间；越低越好。
- 覆盖率与平均宽度：按 50%/80%/95% 区间统计。
- 阶段（增长/峰值/下降等）：仅用于事后分组，不参与当时模型选择。
- 有设计标签时才计算预警精确率、召回率与提前量；没有标签时不计算误报率/召回率。
- 适应恢复标准见代码中的 `RECOVERY_DEFINITION`。

## 7. 对照与消融

对照臂：持续值、固定模型、固定节奏重训、等权、动态加权、适应系统。

消融：删除修订处理、删除异常检测、删除动态权重。结果允许无改善或更差，不硬编码新系统获胜。

## 8. 合成演示数据

固定种子生成 ≥3 个地区、104 周、多发布时间版本，覆盖平稳季节性、真实趋势上升、报告过程变化、延迟与缺失。区分潜在感染、观测病例、住院、检测量、发布版本与模拟真值；真值只用于评价。页面持续标注“合成演示数据”。

## 9. 地图着色与分析记录

全球地图着色不是综合风险分数。国家填色优先使用有人口分母的每 10 万人指标。五档名称（轻微到非常严重）是读图标签：相对档按本图分位数，固定档 `map_burden_v1` 用每 10 万人区间，均不是临床或官方严重等级。无数据、零病例、未报告与过期必须分开，不能把缺失画成低风险。统一周期与“各地最新数据”分开；后者显示时间差。国家值不复制到没有下级边界或没有下级观测的省州。

AI 只解释后端证据包中的已计算数值，不能改观测、阈值或自动确认。分析状态由后端强制：生成中 → 待审核 / 需修正 → 已确认或已驳回。正式记录只能引用已确认版本，并保留“AI 辅助、人工审核”或“手动分析”来源。
