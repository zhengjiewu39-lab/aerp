# 功能实现清单

## 已实现

- 合成演示数据（固定种子、4 地区、104 周、多发布时间版本、四类场景）
- CSV 模板、预览校验、导入批次哈希、版本追加存储
- 按 cutoff 的观测版本查询（vintage / final_time_split）
- 预测模型：持续值、阻尼趋势、计数回归（重训/固定，纯 NumPy IRLS）、等权组合、动态加权、适应规则臂
- 修订轨迹与固定成熟滞后估计
- 异常检测与人工核实状态
- 历史回放、对照臂评分、消融开关、一键消融对照套件、实验导出
- 前端六页中文界面与 ECharts 图（修订轨迹、成熟实况对比、预测范围）
- 本地后台任务（线程池）与重启中断恢复标记
- TransferModel 接口占位；历史疫情资料卡；外部连接器“未配置/尚未验证”

## 部分实现

- 修订不确定性向预测区间的完整传播（已标注尚未完全传播）
- 机制模型：仅用于合成模拟，不从住院反推参数
- 预警技能评价：依赖合成标签；真实标签需用户提供
- Docker Compose：仅可选 API 容器，不是唯一运行方式

## 未实现

- 真实跨疾病迁移模型与权重降低逻辑的完整训练
- CAPE / Delphi-RF / epinowcast / FluSight / Epidata 的已验证连接器
- 生产级分布式任务队列
- 地理边界地图
- GPU / 大语言模型 / 付费 API 依赖功能
