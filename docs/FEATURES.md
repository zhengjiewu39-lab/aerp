# 功能实现清单

## 已实现

- 合成演示数据（固定种子、5 地区、104 周、多发布时间版本、稀疏地区与时变辅助变量）
- CSV 模板、预览校验、导入批次哈希、版本追加存储
- 按 cutoff 的观测版本查询（vintage / final_time_split）
- 预测模型：持续值、阻尼趋势、计数回归（重训/固定，纯 NumPy IRLS）、统一 GLM、地区分层、分层动态更新、等权组合、动态加权、适应规则臂、历史形态类比
- 修订轨迹与固定成熟滞后估计
- 异常检测与人工核实状态
- 历史回放、对照臂评分、消融开关、一键消融对照套件、实验导出
- 前端多病种中文研究工作台（总览、疾病研究、预测比较、迁移、可靠性、实验、数据、历史资料）
- 本地后台任务（线程池）与重启中断恢复标记
- DiseaseSpec 注册表；流感/COVID/RSV 独立 NHSN 信号；登革热来源核查；麻疹合成示例
- 可退出跨疾病迁移原型（本地/固定/退出）与分项可靠性证据
- 历史疫情资料卡；历史形态类比与地区上下文加权；外部连接器“未配置/尚未验证/待接入”

## 部分实现

- 修订不确定性向预测区间的完整传播（已标注尚未完全传播）
- 机制模型：仅用于合成模拟，不从住院反推参数
- 预警联合概率：有轨迹时用 copula/样本轨迹；无轨迹时独立边际并标记 degraded
- 变化诊断准确率：无真实标签不报告；合成标签单独标注
- Docker Compose：仅可选 API 容器，不是唯一运行方式

## 未实现

- 真实 COVID/RSV 全季节 vintage 与登革热可再分发时序
- 已发表标准下的迁移优越性证明
- CAPE / Delphi-RF / epinowcast 的已验证连接器
- 无外部时间戳时的独立公开发布证明（本地哈希链不够）
- 生产级分布式任务队列
- 地理边界地图
- GPU / 大语言模型 / 付费 API 依赖功能
