# 功能状态清单

## 已实现

- 前后端本地启动（FastAPI + React/Vite）
- SQLite 实体：Disease、Region、DataSource、ImportBatch、ObservationVintage、Experiment、ModelRun、Forecast、Alert、Evaluation
- CSV 模板、预览校验、导入哈希与版本保留
- 固定种子合成演示数据（5 地区、104 周、多版本、含稀疏地区与时变辅助变量）
- 截止时间可见性查询（vintage / final_time_split）
- 修订轨迹与固定成熟滞后区间估计
- 预测模型：持续值、阻尼趋势、计数回归（重训/固定）、统一 GLM、地区分层、分层动态更新、等权组合、动态加权、适应规则、历史形态类比
- 异常检测（修订、增长/转折、跨指标不一致、误差恶化）与人工核实状态
- 历史回放、对照臂、消融、MAE/WIS/覆盖率/阶段分组
- 一键消融对照套件（完整 / 删修订 / 删异常 / 删动态权重 / 删分层 / 删动态更新），结果不硬编码胜者
- 总览修订轨迹图；预测页成熟实际值叠加与预测范围、权重展示
- 实验导出（配置哈希、输入哈希、代码/依赖版本、预测与评价）
- 历史疫情资料卡（天花、鼠疫、SARS、新冠）与来源字段
- 历史形态类比库：用归一化定性曲线和对照地区对齐当前序列，再按当前水平缩放 1—4 周；不编造历史病例数
- 地区上下文标签（国家/气候/聚居/年龄结构/医疗容量/流动）用于匹配加权与区间倍率，演示标签不是真实普查
- 地区分层协变量：年龄人口比例、家庭规模、拥挤指数；时变辅助变量：流动、疫苗覆盖率、既往感染估计、学期、措施指数
- 留出地区冷启动；按地区 MAE/WIS/覆盖率；动态更新日志
- 无族裔数据时跳过族裔分析，不生成族裔标签；无分年龄住院时不识别年龄组传播
- TransferModel 接口仍为占位：真实跨疾病病例序列迁移未实现
- 后端科学有效性测试与 API 端到端测试
- Docker Compose（可选，非唯一运行方式）

## 部分实现

- 修订不确定性：已增加可复现抽样，并与点修订对照；未覆盖完整时空相关修订过程
- FluSight vintage：已下载 `time-series.csv`（约 95MB），按 2025-07-05 的 `as_of` 语义转换，并完成 US/CA/NY/TX/PA 多季节子集回放（产物 `research_runs/20261022T202645-ec852c6f`）。该运行不写论文结论。
- 预警评价模块已有定义与指标，真实实验未跑完时不写结论
- 机制模型：合成数据使用简化 SIRS 骨架生成，不从住院反推传播参数；输出仍是住院趋势预测，不改名为传播率
- 时变辅助变量仅用截止前最后可见值或省略，不读取未来协变量；疫苗覆盖率不作免疫比例
- 适应速度恢复指标：有定义与计算，依赖标签与足够评分点
- Delphi Epidata：提供探测命令；仅当探测路径真正返回数据才标为已验证
- 外部 FluSight 提交对照：接口已接入，文件或许可不可用时保持 incomplete
- 预警联合概率默认用 copula 轨迹；无轨迹时独立边际并标记 degraded
- 变化诊断准确率：无真实标签不报告

## 未实现

- 真实跨疾病迁移模型训练与预测输出（形态类比不是该能力的替代声明）
- CAPE / Delphi-RF / epinowcast 的已验证接入
- 生产级分布式任务队列
- 地理边界地图与基于流动矩阵的地区间输入感染模块
- 分年龄住院目标与年龄组间传播识别
- 多病种同时联合训练
- 临床或公共卫生决策支持声明

## 已知局限

- 第一版聚焦单病种、多地区、1—4 周住院预测
- 合成实验成功不代表现实世界有效
- 区间扩大与模型切换规则需靠回放评价，不保证名义覆盖率
- 本地后台任务在进程重启后会标为中断，不会假装仍在运行
- 无人口分母时不输出人均指标；污水原始值不跨采样点合并比较
