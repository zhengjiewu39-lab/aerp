# 功能状态清单

## 已实现

- 前后端本地启动（FastAPI + React/Vite）
- SQLite 实体：Disease、Region、DataSource、ImportBatch、ObservationVintage、Experiment、ModelRun、Forecast、Alert、Evaluation
- CSV 模板、预览校验、导入哈希与版本保留
- 固定种子合成演示数据（4 地区、104 周、多版本、四场景）
- 截止时间可见性查询（vintage / final_time_split）
- 修订轨迹与固定成熟滞后区间估计
- 预测模型：持续值、阻尼趋势、计数回归（重训/固定）、等权组合、动态加权、适应规则
- 异常检测（修订、增长/转折、跨指标不一致、误差恶化）与人工核实状态
- 历史回放、对照臂、消融、MAE/WIS/覆盖率/阶段分组
- 一键消融对照套件（完整 / 删修订 / 删异常 / 删动态权重），结果不硬编码胜者
- 总览修订轨迹图；预测页成熟实际值叠加与预测范围、权重展示
- 实验导出（配置哈希、输入哈希、代码/依赖版本、预测与评价）
- 历史疫情资料卡（天花、鼠疫、SARS、新冠）与来源字段
- TransferModel 接口占位
- 后端科学有效性测试与 API 端到端测试
- Docker Compose（可选，非唯一运行方式）

## 部分实现

- 修订不确定性向预测区间的传播（已标注，未完整传播）
- 外部连接器：统一状态接口已有，真实拉取未配置/尚未验证
- 机制模型：合成数据使用简化 SIRS 骨架生成，不从住院反推传播参数
- 适应速度恢复指标：有定义与计算，依赖标签与足够评分点

## 未实现

- 真实跨疾病迁移模型训练与预测输出
- CAPE / Delphi-RF / epinowcast / FluSight / Delphi Epidata 的已验证接入
- 生产级分布式任务队列
- 地理边界地图
- 多病种同时联合训练
- 临床或公共卫生决策支持声明

## 已知局限

- 第一版聚焦单病种、多地区、1—4 周住院预测
- 合成实验成功不代表现实世界有效
- 区间扩大与模型切换规则需靠回放评价，不保证名义覆盖率
- 本地后台任务在进程重启后会标为中断，不会假装仍在运行
- 无人口分母时不输出人均指标；污水原始值不跨采样点合并比较
